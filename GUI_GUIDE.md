# Guía rápida para usuarios no técnicos

## 1. Abre la aplicación

En la carpeta del proyecto, ejecuta:

```bash
python app.py
```

Se abrirá la ventana principal de la aplicación.

## 2. Elige la carpeta con tus fotos

Haz clic en "Explorar" junto a "Carpeta origen" y selecciona la carpeta que contiene las fotos que quieres organizar.

Ejemplo:

- un disco duro externo
- una carpeta con fotos mezcladas
- una razón de varios años de imágenes

## 3. Busca qué cámaras aparecen

Haz clic en "Inventariar cámaras".

La aplicación revisará la carpeta y mostrará una lista de las cámaras que han tomado fotos allí.

Por ejemplo:

- Panasonic DMC-LZ7
- Canon IXUS
- Sony DSC-HX90

## 4. Selecciona una o varias cámaras

En la lista puedes elegir varias cámaras a la vez.

Esto es útil si quieres organizar solo fotos de la cámara que te interesa, o varias a la vez.

## 5. Pon filtros opcionales

Puedes completar estos campos si quieres:

- Modelo manual: escribe un texto como una marca o modelo si quieres filtrar por nombre.
- Desde: fecha mínima.
- Hasta: fecha máxima.
- Estructura: año, año/mes, año/semana o plano.

## 6. Elige la carpeta destino

Haz clic en "Explorar" junto a "Carpeta destino" y elige la carpeta donde quieres guardar las copias organizadas.

## 7. Pulsa "Organizar fotos"

La aplicación empieza a revisar tus fotos y organiza las copias en la carpeta destino.

La operación no toca los archivos originales.

## 8. Revisa el informe final

Al terminar, la app genera un reporte que te indica qué pasó con cada foto.

Puedes guardar el informe como:

- CSV
- JSON

## 9. Modo prueba (recomendado primero)

Si quieres ver qué haría la aplicación sin copiar nada, activa "Modo prueba (dry-run)".

Esto es muy útil para comprobar antes de procesar una colección grande.

## 10. Importante

- La aplicación crea copias, no mueve originales.
- El destino no puede ser igual al origen ni estar dentro de él.
- Si el programa encuentra fotos ya presentes, puedes elegir si sobrescribir o no.

## Ejemplo real

Tienes un disco externo con fotos mezcladas de:

- cámara de viaje
- móvil viejo
- cámara de familia

La app:

1. analiza el disco
2. detecta las cámaras
3. te muestra la lista
4. seleccionas las que te interesan
5. configura una fecha y una estructura
6. organiza las fotos por año o mes
7. genera un informe final

Al final tendrás una carpeta ordenada sin tocar la original.
